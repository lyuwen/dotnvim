# NeoVim Configuration Repository

This repository contains my personal NeoVim configuration, migrated from Vim.

## Quick Start

```bash
# Clone this repository
git clone <your-repo-url> ~/.config/nvim

# Launch NeoVim (plugins will auto-install)
nvim
```

## Features

- **Leader key**: `\` (backslash)
- **Plugin manager**: lazy.nvim
- **Colorscheme**: Solarized dark
- **LSP**: Python, Lua, Fortran support
- **Completion**: nvim-cmp with LSP integration
- **File explorer**: nvim-tree
- **Git integration**: fugitive, gitsigns

## Requirements

- NeoVim >= 0.10.0
- Git
- A Nerd Font (for icons)
- Language servers (optional, install via `:Mason`)

## Installation

1. **Backup existing config** (if any):
   ```bash
   mv ~/.config/nvim ~/.config/nvim.backup
   ```

2. **Clone this repository**:
   ```bash
   git clone <your-repo-url> ~/.config/nvim
   ```

3. **Launch NeoVim**:
   ```bash
   nvim
   ```
   Plugins will automatically install on first launch.

4. **Install language servers** (optional):
   ```vim
   :Mason
   ```

## Verification

Run the verification script to check your setup:

```bash
~/.config/nvim/verify.sh
```

## Customization

All configuration is modular:

- **Add plugins**: Edit `lua/plugins/*.lua`
- **Change keybindings**: Edit `lua/config/keymaps.lua`
- **Modify settings**: Edit `lua/config/options.lua`
- **Add autocommands**: Edit `lua/config/autocmds.lua`

## Key Mappings

See [QUICKREF.md](QUICKREF.md) for a complete list of keybindings.

Essential mappings:
- `<F5>` - Save file
- `<leader>nt` - Toggle file explorer
- `<leader>h/j/k/l` - Navigate splits
- `<F6>` - Toggle tagbar
- `<F9>` - Run file
